# HelpDesk IT — version web

## Lancer en local
```
pip install -r requirements.txt
python app.py
```
Puis ouvrir http://127.0.0.1:5000

## Prochaines étapes pour en faire un vrai produit vendable

- Remplacer tickets.json par une vraie base (PostgreSQL/SQLite)
- Déploiement sur Render / Railway / VPS
- Abonnement (Stripe) + version gratuite limitée
